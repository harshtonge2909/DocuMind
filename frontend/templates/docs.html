DocuMind Documentation

Introduction

Welcome to DocuMind! This platform is an advanced AI research assistant designed to help you deeply analyze and query PDF documents. Rather than merely matching keywords or passing truncated snippets to an LLM, DocuMind implements an autonomous Agentic RAG (Retrieval-Augmented Generation) pipeline.

The system decomposes complex multi-hop inquiries, searches using both dense semantic vector similarity and sparse BM25 lexical signals, evaluates the draft answer against the source text, and loops back to refine search queries if the answer confidence is below threshold.

Step-by-Step Workflow

1

Upload Your PDF Document

Drag and drop a PDF file into the sidebar dropzone on the Chat page. The background pipeline extracts text using PyMuPDF, segments content into precise child chunks (512 tokens) and context-rich parent chunks (2048 tokens), computes embeddings, and stores them in PostgreSQL with pgvector. The status indicator will transition from uploading → processing → ready.

2

Ask Complex Multi-Hop Questions

Select your uploaded document from the list and submit questions in the chat input. You can ask single-topic queries or complex multi-hop analytical questions. The LangGraph planner node breaks complex queries into focused sub-queries for comprehensive coverage.

3

Examine Grounded Citations

Every response generated by DocuMind includes verifiable citation badges linking directly to the source page numbers and text snippets. Review the citation panel below each answer to inspect the exact context used to formulate the response.

4

Monitor Evaluation Metrics

Navigate to the Evaluation Dashboard at /eval to review real-time Ragas metric benchmarks. Every query is scored for faithfulness, answer relevancy, context precision, and context recall, giving you quantitative insight into retrieval quality.

Architecture & Agentic Pipeline

DocuMind's backend agentic pipeline consists of four cooperating nodes:

1. Planner Node

Analyzes question complexity, classifies query intent, and decomposes multi-part prompts into independent sub-queries.

→

2. Hybrid Retriever Node

Executes vector cosine similarity in pgvector and BM25Okapi lexical matching, merging results via Reciprocal Rank Fusion (RRF).

→

3. Generator Node

Synthesizes cited responses grounded in parent chunk context, attaching exact page offsets and snippets.

→

4. Critic & Reflection Node

Performs hallucination verification. If confidence falls below 75%, it refines queries and loops back to retrieve missing context.

API Endpoints Overview

Method Endpoint Description
POST /api/documents/upload Upload and initiate background ingestion of a PDF document
GET /api/documents List uploaded documents and ingestion statuses
DELETE /api/documents/{id} Delete document and cascade remove all chunks and embeddings
POST /api/query Ask a question (SSE streaming or synchronous response)
POST /api/search Direct hybrid search testing endpoint
GET /api/eval/metrics Retrieve Ragas evaluation metrics and timeline
GET /api/eval/cache-stats Retrieve Redis semantic cache metrics
GET /api/conversations List chat threads for a document
